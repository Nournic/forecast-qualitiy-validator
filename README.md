# fqv – Forecast Quality Validator

Программный комплекс для НИР «Сравнение эффективности 1D-CNN и GRU в задаче автоматического контроля качества
прогнозов финансовых временных рядов» (7 семестр).

## Установка и запуск

```
python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q tests                    # автоматические проверки
python -m experiments.run_all --quick        # быстрая проверка, 1–3 минуты
python -m experiments.run_all                # полный эксперимент
```

Результаты пишутся в `results/` (`summary.json` – сводка, `main_<актив>.json` – подробности, `run.log` – журнал).
Прерванный прогон продолжается той же командой, `--force` пересчитывает всё заново.

## Состав

| Каталог | Содержание |
|---|---|
| `fqv/core` | конфигурация, запуск эксперимента (`ExperimentRunner`), хранение результатов |
| `fqv/data` | загрузка котировок, признаки, метки, скользящая проверка вперёд, синтетические аномалии |
| `fqv/models` | нейросетевые валидаторы (1D-CNN, GRU, CNN+GRU) и эталонные методы |
| `fqv/evaluation` | метрики, статистические критерии, задержка обнаружения, важность признаков, сводный отчёт |
| `experiments` | сценарии запуска |
| `tests` | автоматические проверки, в том числе на отсутствие утечки данных |
